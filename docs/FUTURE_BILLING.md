# 未請求・統合請求（ローカル版）

給液日と請求対象月を別に管理します。未請求明細は翌月だけでなく任意の後続月に選択できます。自動追加・自動確定はしません。

## Schatzの確認手順

1. まず「バックアップ」で現在のJSONを保存します。
2. 「請求前チェック・請求書」を開き、対象月を2026年9月または10月に変更します。
3. 「税・請求書設定」でその月の税率・端数処理を確認して保存します。
4. 「未請求・統合請求」でSchatzを選択します。
5. EG八王子48,100円、デイライン西東京営業所13,000円の行にチェックします。必要に応じて未請求理由・発見日・請求予定月を記録します。発見日は推測で入力しません。
6. 選択内容と小計を確認し、確認チェックを付けて下書きを作成します。
7. 下書きの数量・税抜金額・消費税・税込額を確認してから、その請求書の確認チェックを付けて確定します。
8. 請求済み実績の追跡欄で請求書IDを確認します。確定した明細は未請求一覧から消え、別の月へ二重追加できません。

8月4日の給液日はそのままです。8月の正解値9,630L／税抜570,290円と原本全11枚は変更しません。61,100円を固定調整額にせず、実績2明細の固定売上から計算します。今回の利用者指示に基づき、この2明細を後続月に明示選択して請求できます。過去の仕様説明にある「追加請求の可否は未確定」はこの操作について更新されます。

## TWSの確認手順

1. 「請求先・紐付け」で共通請求先「TWS」を作成します。
2. 「未請求・統合請求」でTWSを選択します。
3. 下の紐付け欄でTWS本牧センターとTWS平塚センターを選び、理由と確認チェックを付けて保存します。
4. 今後のマスター設定と未請求実績だけがTWSへ紐付きます。8月の請求済み実績と各原本の請求先IDは保持します。
5. 対象月の新しい給液実績を登録し、「請求先単位で統合」なら1枚、「給液先別に請求」なら給液先ごとの請求書を作成できます。3か所以上も同じ操作です。

給液先別請求では同じ給液先の複数給液場所を1枚にまとめ、明細の場所を保持します。消費税は請求書ごとの合計に対して計算するため、統合と分割では端数処理の結果が変わる場合があります。

## 保存・修正

通常実績と過去未請求は選択前の一覧で区別し、過去分には元の給液月を表示します。未選択明細は未請求のまま残ります。登録日時は既存給液実績の確認日時／商品登録日時を利用し、旧データにない場合は推測しません。

下書き作成後に明細・税設定を変更した場合は確定を止めます。下書きを取り消して必要な明細を選択し直してください。他の下書きで使用中の同じ明細も選択できません。確定解除には理由と確認が必要で、旧請求書は取消版として保持します。原本照合記録は解除できません。

localStorageと既存JSONバックアップ形式（バージョン5、旧2〜4も読込可）を維持しています。新項目は追加項目として保存し、既存ID・単価履歴・画像・将来AIコードは変更しません。外部サービス接続・課金・公開は行いません。
