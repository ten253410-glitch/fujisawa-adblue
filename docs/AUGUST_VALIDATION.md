## Windowsで確認する手順

1. 更新前に、現在のアプリの「バックアップ・復元」→「JSONバックアップを保存」を押します。
2. GitHubのmainの新しいコードを取得し、アプリのフォルダーで `npm ci`、続けて `npm run dev` を実行します。ブラウザでいつもと同じ `http://localhost:3000` を開きます。localhostと127.0.0.1は別の保存場所です。
3. 「ローカル業務を開く」→土屋または佐藤を選択します。パスワードは不要です。
4. 「請求前チェック・請求書」→「実資料8月検証」を開きます。69件の実績・請求先・原本金額・日付をプレビューできます。商品・貸与・仕入も確認します。
5. 内容を確認してチェックを付け、「照合した8月実データを登録」を押します。既存データを消しません。取込済みの同じ8月資料は二重登録を拒否します。既に一般取込で8月を登録している場合は、バックアップして重複を確認してください。
6. 「請求前チェック」で対象月2026-08を選びます。「数量差異0L」「金額差異61,100円」、Schatzの2件の強い警告と日付差異4件を確認します。請求先を選ぶと、その会社だけを表示できます。
7. 「請求先・紐付け」で、社内名称・正式宛名・住所、給液先と場所の請求先を確認できます。マスターの変更は今後の実績に適用し、過去売上の請求先や単価を再計算しません。未請求の過去売上はチェック画面の明細確認から個別に請求先を設定してください。

### Schatzの追加請求

1. 「請求漏れ候補を追加請求対象にする」を押します。漏れた2件だけが追加請求対象になります。
2. 請求区分「追加請求」、請求作成先「Schatz」を選びます。
3. 今回の請求日・支払期限を入力します。8月原本の9/1・9/30が初期表示されるので、実際に出す追加請求の日付に変更してください。件名は2026年8月分、追加請求の文字が加わります。
4. 確認チェックを付け、「確認して請求書を作成」を押します。EG八王子とデイラインの2明細、税抜61,100円・消費税6,110円・税込67,210円が表示されます。この段階は未確定です。
5. 全明細と請求前チェックを確認し、その請求書の確認チェックを付け、「内容を確認して請求確定」を押します。2件が請求済みになり、金額差異は0円になります。漏れた売上が請求書に含まれていない場合は「未請求の売上があります」で停止します。
6. 「この請求書を印刷・PDF保存」を押し、Windowsの印刷画面でPDF保存またはプリンターを選びます。A4縦、ブラウザのヘッダー・フッターなしを推奨します。確定前の紙には未確定と表示します。
7. JSONバックアップを保存します。原本11枚、追加請求、元の取込行、明細ID、確認者・日時、変更履歴を保存できます。アプリは請求書を自動送信しません。

未確定請求書は取消記録を残して作り直せます。税設定や売上が作成後に変わると、そのまま確定できません。発行済みは上書き・削除しません。

## 一般のCSV・XLSX取込

「過去実績取込」の列マッピング・手動紐付け・重複警告・行ごとの確認は従来通り利用できます。今回のExcelはシート「8月」を選び、「用田プラント形式で給液行をプレビュー」で69件を抽出できます。登録には人の確認が必要です。この経路は給液履歴のみの取込なので、既発行PDFと商品・貸与は自動生成しません。今回の一式を検証する場合は上記「実資料8月検証」を使い、同じ実績を両経路から登録しないでください。

Excelの数式は実行せず、ファイル内に保存された計算結果だけを読みます。結果がない数式やエラーセルは警告します。書式だけの100万行近い空行は除外し、実際の行番号を保存します。ふりがなを顧客名へ混入させません。ファイル10MB、1シート実データ2001行、100列まで。xls・マクロ・PDFの自動読取は未対応です。

## 未確定・今後の課題

- 日付差異4件の正しい実給液日／請求記載日、TSS/TSC表記の正式統一。
- 翌月以降の締め期間・税設定、請求書番号の採番、繰越・値引き・返品・貸倒・支払状況。8月ルールを他月に自動適用しません。
- 税抜売上そのものに円未満が出た場合の丸め。積は正確な小数として保持し、推測した丸めを入れていません。
- 実績の数量・固定単価の訂正、発行済み請求の取消・返金・再発行手順。現在は履歴を保護します。
- 取込資料にない納入先住所・担当者・伝票番号は補いません。確認者と実作業担当者を区別します。
- 今後はPDF照合記録の一般入力・別名辞書・訂正伝票・入金消込があると、毎月の照合負担を減らせます。AIは将来用コードのみ維持し、今回は使用していません。

## テスト

実資料69給液と11請求先の金額を固定した回帰データで、数量・単価・税抜・消費税・税込・既知の請求漏れを検証します。Schatz原本は不具合を含む資料として扱い、正しい税抜631,390円とは別に保存します。
追加請求2件、重複請求防止、未請求明細の欠落拒否、単価・過去請求の固定、税変更後の確定拒否、取消後の再作成、JSON復元を自動検証しました。ブラウザではPC・スマートフォン幅で確認取込・警告・追加請求確定・印刷PDF・再読込を検証しています。原本xlsxを指定するブラウザテストは `AUGUST_WORKBOOK_PATH` に添付ファイルのパスを設定すると実行でき、原本はリポジトリへ含めません。

今回の最終確認：型チェック・本番ビルド成功、自動テスト26件成功、添付原本xlsxを含むPC／スマートフォン幅のブラウザテスト20件成功。
