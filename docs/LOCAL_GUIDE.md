# このPCだけで業務を試す手順

追加契約・APIキー・クラウド設定は不要です。最初から最後まで税抜の業務検証ができます。

## Windowsで更新して起動する

1. 旧版を起動している黒い画面で Ctrl + C を押して停止します。
2. GitHubのリポジトリで「Code」→「Download ZIP」を選び、別のフォルダーに展開します。
3. 展開したフォルダーのアドレス欄に cmd と入力し、Enterを押します。
4. 黒い画面で npm ci と入力し、終了を待ちます。
5. npm run dev と入力します。この黒い画面は閉じないでください。
6. 以前と同じブラウザで http://localhost:3000 を開きます。
7. 土屋または佐藤を選び、「ローカル業務を開く」を押します。パスワードは不要です。

同じブラウザ・同じアドレスなら以前の保存データを引き継ぎます。localhost と 127.0.0.1 は別の保存場所です。別のPC・別のブラウザでは自動共有しません。
「デモを開く」は初回だけサンプルを用意します。保存済みデータがあれば、どちらの入口でも続きから開きます。既存データを消してサンプルへ戻す動作はありません。

## 一度通して試す

1. 「顧客検索」→「顧客を追加」で顧客名・会社名・会社住所・電話・備考を保存します。
2. 「場所を追加」で車庫や現場を登録します。1社に複数登録できます。単価と適用開始日も追加します。
3. ホームの「電話受注」を開きます。受注経路は電話・LINE・FAX・メール・紙・画像から選べます。
4. 顧客と登録済み給液場所を選び、依頼数量・希望日・連絡先・備考を入力して受注を登録します。
5. 案件の「給液予定日」を入力し、「日程・メモを保存」を押します。スケジュールの日付指定・日程未定でも確認できます。LINE回答文をコピーできます。
6. 給液後「給液終了を記録（納品書待ち）」を押し、納品書を撮影または画像で追加します。
7. 同じ案件を開き、納品書を見ながら実際の給液日・実給液量・担当者・備考を入力します。依頼数量とは別の入力です。
8. 給液日時点の税抜単価と計算結果を確認し、確認チェックを付けて「給液実績と売上を登録」を押します。
9. 「売上・請求管理」で顧客・月を選ぶと、給液日・数量・固定単価・税抜金額・合計を表示します。「一覧CSV」で表を保存できます。
10. 対象売上を選択し、変更メモと確認チェックを付けて「選択分を請求済みにする」を押します。検証用の状態記録で、請求書発行・送信はありません。
11. 顧客に新しい単価履歴を追加し、以前の売上単価と金額が変わらないことを確認します。
12. 「バックアップ・復元」→「JSONバックアップを保存」でファイルを保存します。画像も含まれます。
13. 復元を試す場合は「バックアップJSONを選択」から保存したファイルを選び、件数を確認してチェックし、「確認して復元」を押します。現在のデータを置き換える前に、復元前データもダウンロードします。
14. ブラウザを閉じ、同じアドレスで開き直して続きが残ることを確認します。

受注画像も「受注画像取込」→画像選択→「手入力で確認へ」で使えます。AIは停止中です。入力を確認し、既存顧客を選んでから受注登録します。

## 保存の注意

通常のブラウザで利用し、作業終了時にJSONバックアップを保存してください。ブラウザのサイトデータ削除・シークレットモード終了・PC故障でlocalStorageは失われます。保存容量が不足すると今回の変更を保存せず、エラーを表示します。
CSVは売上一覧の出力です。全データの復元にはJSONを使います。複数タブの古いデータによる上書きを検出した場合は、ログアウトして入り直してください。
