# 請求画面の使い方

「請求前チェック・請求書」を開くと、通常業務の「① 請求書を作る」が最初に表示されます。

| 入口             | 使う場面                                                                   |
| ---------------- | -------------------------------------------------------------------------- |
| ① 請求書を作る   | 毎月の通常請求。請求先を選んで明細・金額を確認し、プレビューから確定・印刷 |
| ② 未請求を処理   | 過去月を含む未請求の一覧。明細を選択して9月・10月など任意の後続月へ請求    |
| ③ 統合請求設定   | TWS本牧・平塚など、複数給液先を同じ請求先へ紐付け。翌月以降も継続          |
| ④ 月次集計・照合 | 全体・請求先別集計、原本との差額、8月実資料、有償商品・無償貸与・BIBの確認 |
| ⑤ 請求先設定     | 正式名称、住所、締日、請求日、支払期限、請求条件、紐付け、税・端数設定     |

## 普段の請求

1. 「① 請求書を作る」で対象月を選びます。
2. 請求先の行の「選択」を押します。給液量・税抜予定額・明細件数を見て選べます。
3. 選んだ請求先の今回月の明細だけが出ます。数量・固定単価・金額・日付を確認します。今回月の明細は最初に選択されており、不要な明細はチェックを外せます。過去未請求は自動追加しません。
4. 確認チェックを付け、「請求書プレビューへ」を押します。税設定がない月は「⑤ 請求先設定」内で確認・保存してください。
5. 請求書を確認し、確認チェックを付けて「この請求書を確定」を押します。
6. 「この請求書を印刷・PDF保存」を押します。Windowsの印刷画面でプリンター、またはPDF保存を選びます。

下書き作成後の明細変更は「下書き取消（選択し直す）」で旧版を保持してから選び直してください。同じ明細は別の下書き・確定済み請求書へ重複追加できません。

## Schatzの8月未請求2件

1. 「② 未請求を処理」を開きます。請求先を選ばなくても全請求先の未請求明細が表示されます。
2. EG八王子740L・48,100円、デイライン西東京営業所200L・13,000円にチェックします。最初の選択に合わせて請求先が絞られます。請求先ごとに操作してください。
3. 「追加する請求対象月」を2026年9月、10月などに変更します。明細の選択は保持されます。
4. 940L／税抜61,100円を確認し、下書き作成→プレビュー確認→確定と進みます。
5. 確定後は未請求一覧から消え、請求書IDが追跡欄に残ります。同じ2件を10月などに再度追加できません。

給液日は2026年8月4日のままです。8月原本のSchatz 9,630L／570,290円、全体40,500L／税抜2,823,058円／消費税282,305円／税込3,105,363円は書き換えません。61,100円は固定の調整額ではなく、2実績の数量×固定単価から算出します。

## TWSの統合・変更・解除

1. 必要なら「⑤ 請求先設定」で共通請求先「TWS」を追加します。
2. 「③ 統合請求設定」でTWSを選択します。
3. 本牧・平塚など対象の給液先をチェックし、変更理由と確認チェックを付けて保存します。
4. 設定は翌月以降も継続します。「① 請求書を作る」でTWSを選ぶと、その請求先に属する今回月の明細が出ます。
5. 「請求先単位で統合」で1枚に、「給液先別に請求」で給液先ごとの請求書にできます。どちらでも各明細に給液先・場所・商品を表示します。
6. 解除・変更時は、変更後の個別請求先を選び、戻す給液先だけにチェックして理由と確認を付けて保存します。

給液先ID・単価履歴は統合しません。今後のマスターと未請求実績の請求先だけを変更し、既発行原本・請求済み実績は保持します。

## 過去データ・バックアップ

「④ 月次集計・照合」の「既存請求の管理」で原本と既存の請求書を確認・印刷できます。従来の一括作成操作は、この管理画面の折り畳み欄に残しています。通常の作成画面には集計一覧・設定・過去のプレビューを並べません。

更新前と検証後には「バックアップ・復元」でJSONを保存してください。未請求理由・状態、統合設定、請求書IDも復元できます。保存形式・既存ID・CSV/XLSX取込・将来AIコードは維持し、外部サービス・課金・本番公開は追加していません。
