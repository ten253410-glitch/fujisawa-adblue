# 請求画面の使い方

「請求前チェック・請求書」には5つの入口があります。

| 入口             | 役割                                                                     |
| ---------------- | ------------------------------------------------------------------------ |
| ① 請求書を作る   | 選んだ請求月の通常明細と、②からその月へ追加済みの明細で請求書を作る      |
| ② 未請求を処理   | 請求漏れを見つけ、次に請求する月へ送る。ここでは請求書を作成・確定しない |
| ③ 統合請求設定   | TWS本牧・平塚など複数給液先の請求先を統合。翌月以降も継続                |
| ④ 月次集計・照合 | 全体・請求先別集計、原本照合、商品・貸与・BIB、既存請求書の管理          |
| ⑤ 請求先設定     | 正式名称・住所・締日・請求日・支払期限・条件・紐付け・税設定             |

## ① 普段の請求書作成

1. 「① 請求書を作る」で対象月を選びます。
2. 請求先の行の「選択」を押します。
3. その月の通常明細と、②でその月へ追加済みの明細だけが表示されます。未処理の過去請求漏れは自動的に混在しません。
4. 数量・固定単価・税抜金額・税・日付を確認し、確認チェックを付けて「請求書プレビューへ」を押します。
5. 請求書を確認し、確認チェックを付けて「この請求書を確定」を押します。
6. 「この請求書を印刷・PDF保存」を押し、Windowsの印刷画面でプリンターまたはPDF保存を選びます。

税設定がない月は⑤で確認・保存します。②で月へ送るだけの操作には税設定は不要です。

発行済みの通常請求は「○年○月の通常請求は発行済み」と表示します。その元月の残った請求漏れを通常候補へ再度混ぜません。元月の原本は保存済み請求書として保持します。

## ② Schatzの8月請求漏れを9月へ送る

1. 「② 未請求を処理」を開きます。請求先未選択でも全請求先の未処理一覧が表示されます。必要ならSchatzで絞り込みます。
2. EG八王子740L・48,100円、デイライン西東京営業所200L・13,000円の2件をチェックします。
3. 「請求する月」で「2026年9月」を選びます。10月・それ以降も選べます。一覧にない将来月は「一覧にない請求月を指定する」から入力できます。
4. 必要なら「未請求理由（一括・任意）」に「8月請求漏れ」などを入力します。空欄なら元の理由を保持します。未記録の発見日は処理日（日本時間）で自動記録し、既存の発見日は保持します。
5. 集計欄の「今回選択：2件」「選択数量：940L」「選択税抜金額：61,100円」「追加先：2026年9月請求」を確認します。
6. 「選択した2件を2026年9月請求へ追加」を押します。この段階では請求書を作成・確定しません。
7. 「① 請求書を作る」で2026年9月・Schatzを選びます。2件が「2026年8月未請求分」と表示され、9月の通常明細と合算できます。
8. 請求書を確認して確定します。請求済みの2件は再び10月などへ送れません。

実給液日は2026年8月4日、単価は65円/L、本来の対象月は2026年8月のまま保持します。実際に載せる請求月だけを別項目で記録します。

8月原本はSchatz9,630L／税抜570,290円、全体40,500L／税抜2,823,058円／消費税282,305円／税込3,105,363円のままです。61,100円を原本へ補正せず、実績2件を後続の請求に算入します。

## 状態・取消・個別編集

- **未請求**：まだ請求する月を指定していない明細。選択可能です。
- **○月請求へ追加済み**：①のその月で作成する候補。他の月へ二重追加できません。
- **請求書作成中**：その明細を下書きに使用中。他の下書き・月へ二重追加できません。
- **請求書確定済み**：請求書IDで追跡できます。通常の未請求操作では変更できません。

追加を間違えた場合は②の「請求月へ追加済み・請求書作成中」で明細を開き、取消理由を入力して「請求月への追加を取り消す」を押します。再び未請求に戻り、取消履歴を保持したまま別の後続月を指定できます。

下書き作成後は、先に①のプレビュー／保存済み請求書から「下書き取消（選択し直す）」を行ってください。請求月への追加自体は残るので、必要ならその後②で追加も取り消します。

**確定後の変更は通常操作と分離しています。** ①の「確定後の変更は管理画面で行う」または「④ 月次集計・照合」→「既存請求の管理」で、理由と確認を付けて確定を解除します。旧請求書は取消版として保持し、原本照合記録は解除できません。解除後も追加済みの請求月は保持し、二重追加を防ぎます。必要な月変更は、その後②の追加取消から行います。

個別の理由・発見日を修正する場合だけ、未請求行の「個別編集」を開きます。通常は複数選択・請求月選択・任意の一括理由・追加の4操作です。

## 統合請求・保存

③で共通請求先TWSを選び、TWS本牧・平塚をチェックして理由と確認を付けて保存します。設定は継続し、①でTWSを選ぶと両給液先の明細が表示されます。給液先ID・単価履歴は統合せず、明細には各給液先・場所・商品を表示します。解除・変更は、変更後の個別請求先を選んで該当給液先だけを紐付け直してください。既発行原本・請求済み実績は保持します。

「バックアップ・復元」のJSONには、本来の対象月、追加先請求月、追加者・日時、理由・発見日、取消履歴、請求書ID、統合設定も保存します。旧JSONも読込可能です。更新前と検証後にバックアップを保存してください。外部サービス・課金・本番公開は追加していません。
